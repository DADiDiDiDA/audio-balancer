音频均衡器 v1.2 · 使用说明
==========================

一个程序同时做两件事：响度均衡 + 游戏时自动静音。
只有一个托盘图标、一个窗口，不再需要 AudioBalance 和 background_muter。

一、它怎么工作
--------------
    播放器 → CABLE 虚拟声卡 → 本程序 → 耳机/扬声器

  * 从 CABLE 的回环采集正在播放的声音；
  * 按 ITU-R BS.1770-4 测响度（和专业广播同一个标准）；
  * 超过目标响度就平滑压低，再做软限幅防爆音；
  * 用 RAW 模式送出，绕过 Nahimic / Voice Clarity 等音效，所以不会变调、不会"电音"。

所以：浏览器、游戏、音乐、视频的声音都会被统一处理。
全链路约 0.1 秒延迟（蓝牙耳机还会叠加自己的延迟）。

前提：系统默认输出必须设为 CABLE（你现在是 CABLE In 16ch）。
     换耳机不用手动改 —— 见下面「三、换耳机」这一节。

二、界面
--------
顶部：运行状态 / 当前响度 / 增益（含"已绕过音效"）/ 是否在游戏中
「响度均衡」：目标响度、最大衰减、限幅上限、处理前降低、直通模式
「自动静音」：列表程序音量、压到、渐变时长、两个静音规则开关、程序名单
「音频设备」：监听输入（CABLE）、输出设备（耳机）、自动接管开关、当前系统默认输出
「关于」：版本与原理

任何改动都立即生效（不用重启），并在约 0.4 秒后自动写入 config.json。
右下角会显示"已保存 20:31:05"；想立刻落盘可以点「立即保存」。

三、换耳机（自动接管）
----------------------
   原来：系统默认输出 = CABLE
   你想要的：系统默认输出 = 耳机A，但声音仍要被处理

现在只需要一步：到 Windows「设置 → 系统 → 声音」把输出设备改成耳机A。

程序会：
  1. 把耳机A 记成"输出设备"（0.2 秒内自动重连过去）；
  2. 立刻把系统默认输出改回 CABLE；
  3. 之后所有程序的声音继续走 CABLE → 本程序 → 耳机A。

也就是说：在 Windows 里点一下就能换耳机，不用回来改配置。
如果不想让它这么做，到「音频设备」页关掉「自动接管」即可。

四、处理前降低
--------------
在「响度均衡」页，可以填 -40 ~ 0 之间的分贝数（回车或点箭头即生效）。

作用：把采集到的声音先降低这么多，再进增益和限幅。
适用：响度本来就很足、峰值老是顶到限幅的内容（某些游戏、直播、广告）。

注意它等于整体再降一次音量：
   最终响度 = 目标响度 + 这个值（填 -6 就比目标再低 6dB）
想更安静就填 -6 左右；觉得声音偏小就填 0。

五、自动静音
------------
名单里的程序（进程名，如 StarRail.exe，不区分大小写）有两种处理方式，
两个开关可以各自开关：

  * **切到后台时静音它**（默认开）
    名单里的程序最小化 / 挂机 / 被别的窗口盖住时，只把**它自己**压到「压到」的值。
    这样挂机游戏不会在后台一直响。

  * **在前台时压低其它程序**（默认开）
    名单里的程序在前台时，把**其它程序**（音乐、浏览器）压到「压到」的值，
    离开后自动恢复成你原来的音量。

名单外的程序任何时候都不动；本程序和系统提示音永远不动。
顶部会显示「已静音：xxx.exe」或「前台：xxx.exe · 已压低 N 个」。

六、托盘
--------
右键托盘图标：打开主界面 / 响度均衡（勾选）/ 自动静音（勾选）/ 退出。
关闭窗口只是收到托盘，程序继续工作。
双击 exe 会唤出已经运行的窗口，不会开第二个。

七、安全边界
------------
  * 不改设备音量（只改默认输出是哪个设备，且只在你先在 Windows 里改过之后才改回去）；
  * 不改音频驱动、不加内核驱动、不写 APO；
  * 自动静音只动被判定为"后台"的程序，退出时恢复你原来的音量；
  * 所有处理在本机完成，不联网。

八、做不到的事
--------------
  * 独占模式（Exclusive）或 ASIO 输出的程序绕过系统混音器，管不到；
  * 只压不升：安静的内容不会被硬拉响（那需要动系统音量，本程序坚持不做）；
  * 同一时刻所有程序被统一处理，不做逐程序独立归一化。

九、文件
--------
音频均衡器.exe    主程序
config.json       配置（删掉恢复默认）
