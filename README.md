# 音频均衡器（AudioBalancer）

一个常驻托盘的 Windows 音频工具：**响度均衡 + 自动静音**，一个程序、一个托盘、一个界面。

> 起因：看视频 / 打游戏时声音忽大忽小（爆炸吓人、对话听不清），
> 商业方案 AudioBalance 很好用但是闭源收费，于是自己用 Python 写了一个。

## 架构（v1.4）

```
音频均衡器.exe           核心进程：引擎 + 静音 + 设备守护 + 托盘，无窗口、无 Tk
音频均衡器.exe --ui      UI 进程：只跑界面，通过 JSON 状态文件 / 命名事件与核心通信
```

- 双击 exe：启动核心并拉起 UI；双击第二个 exe：只把已有 UI 叫到前台
- 开机自启 `--minimized`：**只启动核心**，不创建 UI 进程，省内存
- 关掉 UI 窗口：UI 进程真的退出；核心继续处理音频；托盘「打开主界面」再拉起
- 核心每 0.2s 原子写 `.audiobalancer_status.json`，UI 只读；UI 写 `config.json`，核心监视 mtime 热重载

## 功能

**响度均衡（BS.1770）**

- 从 VB-CABLE 虚拟声卡回环采集系统声音，按 ITU-R BS.1770 测量节目响度，
  再把响度送进目标区间，经软限幅后输出到耳机/扬声器。
- 两种处理方式：
  - **自动电平**（默认）：目标是「区间」而不是绝对值。低于范围就提上来（可限最大提升），
    高于范围就压下去（可限最大衰减），落在范围内完全不动 —— 不会对每一帧都追目标，听感稳。
  - **仅限制**：只压峰值，安静内容原样通过，绝不放大底噪。
- 处理前降低：给限幅器留余量，峰值老顶天花板的内容先降几 dB 再处理。
- **WASAPI RAW 输出**：绕过 Nahimic / Voice Clarity / Realtek APO 等"语音美化"音效，
  避免音乐被当成人声压缩成电音（本项目的原始动机）。

**自动静音（挂机静音）**

- 名单里的程序切到后台（最小化 / 挂机）→ 自动静音它自己（默认开）。
- 名单里的程序在前台 → 把其它程序压低（默认关，可选）。
- 只动会话音量，退出或关闭开关时按原值恢复；绝不碰系统提示音和 audiodg。

**自动接管默认输出**

- 在 Windows 里把默认输出换成耳机 → 本程序自动把它接成输出设备，
  再把系统默认改回虚拟声卡。下次换耳机只要在 Windows 里点一下。
- **远程桌面默认不接管**（v1.7.1）：程序跑在 RDP 会话里（或本地会话被远程桌面挤掉）时，
  默认完全不碰声音——不处理、不改默认输出，RDP 的声音原样走对面设备；
  想接管就在「音频设备」页打开「在远程桌面中接管」（托盘菜单也有）。

**音量均衡预设**

- 自定义 / 人声 / 均衡 / 电影 / 夜间，一键设好目标响度、允许范围、最大提升与衰减、跟随快慢；
  之后手动微调会自动变成「自定义」。
- 「自定义」是显式状态（`config.json` 的 `loud_preset`）：可以直接点过去、重启后还在，
  不需要先改个数值（v1.7.3 修复）；重复点同一档会把整套参数重新套用。
- 每个选项标题旁有「!」：鼠标悬停就能看到这一项到底在做什么、调大调小的影响。

**响度测量与增益策略（v1.8.0 / 1.8.1）**

- K 加权系数按 BS.1770 的标准双线性设计**按实际采样率现算**（v1.8.1）：48kHz 下与标准
  公布的系数表逐位一致；以前用的 RBJ 近似参数让中频读数偏低 0.25 dB（1kHz 正弦读 −20.25
  而不是 −20.0），44.1/48/96kHz 之间的读数差已压到 0.02 dB。
- BS.1770-4 两级门控：绝对 −70 LUFS + 相对 −10 LU，滑动窗口内门控；长静音、片头片尾
  不会把测量值拉低，避免"静音后一有声音就过响"的跳变。
- 低电平拐点（护底噪）：比目标低 34 dB 以上的内容**完全不提升**，往上 10 dB 内线性恢复；
  正常内容照常提升，底噪/呼吸声不会被一起抬起来。
- 真峰值限幅：8 点插值估采样间峰值 + 2 ms 前瞻 + 立体声联动，只降增益不改波形，
  天花板即 `limiter_ceiling_db`（默认 −1 dBTP），转码后也不削波；状态栏实时显示 dBTP。
  直通也走同一个限幅器（天花板 0 dBTP），所以切换直通不会让时间轴跳 2 ms。
- 自动电平测的是**增益前**的响度，所以调 Windows 音量不会和 AGC 打架（音量才是音量）。

**稳定性（v1.8.4）**

- **模拟器 / 游戏切到前台仍然没声音**：静音模块把「接管前的音量」只记在内存里。
  一旦均衡器重启（或记录时读到的已经是 0），那个 0 就被当成你自己设的音量，
  前台算出来还是 0 —— 于是把模拟器切到前台、甚至退出均衡器都不会恢复。
  现在 0 一律不当作原值，并把「哪个程序原本多大声」写进 `mute_state.json`，
  重启后能认出「那个 0 是我们压的」并还原；前台也确保至少有声音。
- 日志里会记一行「自动静音：压低 xxx（前台 yyy）/ 已全部恢复」，
  以后遇到「前台没声音」可以直接翻日志看是哪一拍压的。

**稳定性（v1.8.3）**

- **运行中调好的参数，重启后又变回去**：核心进程和界面进程各持一份配置快照。
  以前核心退出时会把内存里的整份快照写回，把界面刚改的目标响度 / 处理前降低 / 静音名单
  覆盖成启动时的旧值。现在**没有改动就不写盘**，有改动也只把「自己改过的键」合并进磁盘最新内容。
- **从静音名单里删掉的程序仍然没声音**：恢复逻辑以前只认音频会话标识，会话一重建
  （程序重开、暂停后重新出声）就再也认不出"这是我压低过的"，音量永久停在 0。
  现在按「会话标识 → pid + 进程名」双匹配；会话暂时消失时只要进程还活着就保留记录，
  删名单、关总开关、程序重开都能还原到用户原来的音量；用户自己拖过的音量以用户为准。
- **静音名单按 A-Z 排列**，添加/删除后保持有序；删除按选中的名字删，不再依赖显示顺序。
- **渐变时长按真实经过时间计算**（指数时间常数），设 300ms 就是 0.3 秒量级，
  以前实际要约 0.9 秒，设 1000ms 和 2000ms 听感几乎一样。
- **前台不再把你的音量拉满**：名单里的程序切到前台时，以前直接把音量设成「名单程序在前台时」
  那一项（默认 100%），会盖掉你手动调的音量。现在以「你自己设的音量 × 该项比例」为准，
  100% 就是完全不动你的音量。
- **配置热重载不再盖掉本进程还没落盘的改动**：设备守护刚改好输出设备、界面又写了一次配置时，
  以前会把设备改动盖回旧值。
- 开机自启写注册表失败时，开关会重画回真实状态（以前会停在错误的位置）。
- 回归：`verify_persist.py` 19 项 + `_audit_buttons.py` 25 项（四个页面所有按钮 / 开关 /
  分段 / 滑块 / 侧边导航 / 托盘菜单逐个触发）全通过。

**稳定性（v1.8.2）**

- 界面刷新链单次异常不再中断（`_poll` 用 try/finally 保证 `after()` 一定排下一次）；
  以前状态文件还没生成就切到「音频设备」页，一次 KeyError 会让界面永久停止刷新。
- 配置保存失败保留「未保存」并 1 秒后重试；核心与界面两个进程改为**按键合并写盘**
  （只写自己改动过的键），不再整份覆盖对方刚改的值；读取时按默认值类型校验，
  配置里出现 `null` / 字符串不会让整页渲染失败。
- 画布重绘前销毁内嵌的 Tk 控件（下拉框 / 输入框 / 列表框），反复切页不再累积。
- 自动静音只在真的要改某个会话时才记录原音量；用户自己拖过音量条就以新值为准，
  退出时也只还原自己确实改过的会话。
- 退出时在控制线程内还原音量（COM 会话对象属于该线程），避免跨线程失败留下 0 音量。

**其它**

- 资源占用低：默认 10ms 缓冲时，静音空闲约 3% CPU、持续播放约 12~14%（v1.7.2 优化：
  静音快路径跳过整条处理链、按设备周期睡一次代替 2.5ms 轮询、设备探测只取端点 id；
  v1.8.0 的真峰值限幅另占约 1~2%）。
- 缓冲可调：默认 15ms，端到端延迟约 68ms（11ms 约 52ms；设备缓冲自动留两块余量防刺啦，
  另有真峰值限幅的 2ms 前瞻）
- 环绕声：CABLE 配成 5.1/7.1 时自动多声道采集并按 BS.775 下混到立体声，中置人声不丢
- **Windows 音量控制**：回环采集不受 CABLE 的音量滑块影响，引擎只读取它作为最终输出增益
  （绝不修改用户的系统音量）。音量是对数曲线：
  20% = 正常音量、100% = +10dB（都可调），低段细腻不再一拖就没声。
- 亚克力（毛玻璃）界面，跟随系统深色 / 浅色；左侧导航 + 卡片式设置。
- 任何改动立即生效并自动保存（右下角显示 保存中… / 已保存，仍可手动点）。
- 单实例：重复启动会把旧实例的窗口叫到前台，而不是再开一个；用 Global 内核对象跨会话生效，
  远程桌面和本地控制台也不会各起一个（避免抢虚拟声卡报「找不到 CABLE」）。

## 音频链路

```
播放器 → CABLE Input（系统默认输出）
       → 本程序从 CABLE 回环采集
       → 去直流 + BS.1770 响度测量（测量在增益之前，闭环天然稳定）
       → 增益（自动电平 / 仅限制） + 软限幅
       → WASAPI RAW → 耳机
```

## 使用前提

1. Windows 10 / 11
2. 安装 [VB-CABLE](https://vb-audio.com/Cable/) 虚拟声卡
3. 系统默认输出设为「CABLE Input / CABLE In 16ch」

## 构建

```bash
pip install numpy soundcard pycaw comtypes psutil pillow pystray pyinstaller
python -m PyInstaller 音频均衡器.spec --noconfirm --clean
```

## 目录

```
src/
  main.py          核心入口：单实例、托盘、调度线程、配置热重载、状态发布
  ui_main.py       UI 进程入口：状态代理 + 按需启动
  ipc.py           状态文件 / 命名事件
  engine.py        音频引擎：采集 → 测量 → 增益+音量曲线 → 限幅 → RAW 播放
  loudness.py      K 加权 + 滑动 LUFS
  dsp.py           直流阻塞等
  wasapi_raw.py    IAudioClient2 + AUDCLNT_STREAMOPTIONS_RAW 播放器
  muter.py         自动静音（会话音量）
  device_guard.py  默认输出接管（IPolicyConfig）
  theme.py         亚克力 + 深浅色 + DPI
  ui_kit.py        自绘控件（开关 / 滑块 / 分段 / 按钮）
  gui.py           界面
  config.py        配置读写（原子写入 + 防抖自动保存）
```
